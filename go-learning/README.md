# Go Learning Resources

This directory contains Go programming examples and learning resources to complement the AWS Amplify React template.

## Getting Started with Go

### Installation

1. Download and install Go from [golang.org](https://golang.org/dl/)
2. Verify installation: `go version`

### Running the Examples

Each example can be run using:
```bash
go run <filename>.go
```

## Examples Included

1. **hello.go** - Basic "Hello, World!" program
2. **basics.go** - Go fundamentals (variables, types, functions)
3. **structs.go** - Working with structs and methods
4. **webserver.go** - Simple HTTP web server example

## Project Structure

This Go learning module is independent from the React frontend but can be used to:
- Learn Go programming fundamentals
- Create backend services for the React app
- Understand full-stack development
